## Featured Project ⭐

### [SmartOps Agent](https://github.com/sanchezign/smartops-agent)

AI operations agent for businesses that run on WhatsApp. It reads price lists, orders and questions sent as text, photos, PDFs, spreadsheets and voice notes, keeps the product catalog up to date, and sends the team only what needs action.

- 🧠 3 agents orchestrated with **n8n** and **Claude** (structured outputs validated with Zod), with human review for uncertain data
- 🛡️ Prompt injection defense: a real-model evaluation passed **8/8** cases
- ✅ **1,900+ automated tests**, **80% mutation score**, CI/CD with GitHub Actions
- 💸 Total AI spend during development: about **USD 0.32**
